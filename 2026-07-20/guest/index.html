1このセッションについて

0:00〜

合計3回の登壇企画・第1回目。Shinさんが「AIを使って受講生自身が銘柄を発掘できるようになってほしい」という意図のもと、AI活用の最前線を走る西田氏をゲストに招いた約38分のフリートーク。ファンド運営の実態から、一般投資家向けの実践的AI活用術まで幅広く語り合いました。

🎯 招待の背景： 暗号資産の金商法組み込みが決定し、「私が何を買った・売った」というスタイルが来年から難しくなる見通し。そこで「AIを使って受講生自身が銘柄を見つけられる」方向へのピボットを模索する中で、ファンドでAIを実際に活用している西田氏に白羽の矢が立った。

2フリートーク 対話録

3:00〜

Shinさんが事前に用意した質問リストに沿って、フリートーク形式で進行。

Q1 AI が出てきて投資のやり方は変わりましたか？ 7:00〜
投資の仕事は「準備が9割以上」。情報収集と分析に大半の時間を割き、実際に売買するのは一瞬（Shinさんは年2回程度）。その「準備」の部分が劇的に変わった。
📊 ビフォーアフター： 以前は専門のデータ分析官（大学の研究者のようなイメージ）に検証を依頼すると、数週間〜数ヶ月かかっていた。AIが登場してからは自社完結で、分析の粒度が上がりながらも数時間で完結するようになった。
また「エッジ（優位性のある売買ポイント）」の有効期間が以前の5〜10年から短縮されており、仮説検証のPDCAサイクルを高速で回し続けることが必須になった。そのスピードアップにAIをフル活用している。
Q2 逆に全く変わらなかった部分は？ 10:00〜
AIが取ってこれる情報は「世の中に落ちている情報」だけ。情報・スキル・行動力があっても、根本的な「考え方（メンタリティ）」がマイナスなら掛け算で結果はゼロになる。この本質的な考え方の部分はAIでは変わらない。
💡 情報ばかり集めて頭でっかちになり、本質的な考え方を知らないまま間違った行動をするのが典型的な失敗パターン。本質を押さえた上で正しい情報・知識があれば、結果は導きやすくなる。
Q3 結局のところ、AI は投資に役立つのか？ 13:30〜
もちろん役立つ。ただし認識として重要なのは「AIはただのインフラになる」ということ。
📱 スマホのたとえ： 今はまだスマホが出たての頃と同じ段階。「タッチ決済って役に立つの？」と聞くようなもの。浸透してしまえば「そんなのは当たり前」になるだけ。今は移り変わりの段階だから疑問が出るのは当然で、インフラになれば何てことはない。
Q4 最近聞いた流行りの使い方は？ 17:00〜
一般投資家の間で流行っている活用例として3つ紹介：
🔧 ①自動売買EA・サインツール： Claude Codeなどで2分程度で作れる時代に。「SaaS is dead」——欲しいものが自分で作れてしまうので、既製品に何十万円も払う必要がなくなりつつある。

📐 ②資金管理ツール： 損失許容率・エントリーと損切り設定から自動でポジションサイズを計算。資金管理ミスがなくなる。実用性が高く特にニーズあり。

📊 ③独自インジケーター： トレードする時間帯を区切るなど、自分専用のツール作成。
Q5 試したけどダメだったことは？ 19:00〜
テクニカル分析のAI化が最大の難関。ファンダメンタルズ分析はAIが得意（情報→分析）だが、テクニカルはスポーツ的な要素がある。
⚽ メッシのたとえ： AIにメッシの蹴り方を学習させることはできる。しかし試合でキーパーや相手の動きに合わせるのはできない。メッシが言語化できていない「スキーマ（感覚知）」があるから。自転車の乗り方を言葉で説明できても、それを聞いて乗れるようにはならないのと同じ。

⏳ AI にテクニカル分析を実用レベルで使えるようになるまで、まだ5年程度かかるという見解。
Q6 Claude Code は必須？ ChatGPT で足りる？ 24:00〜
目的によって用途が違う。
🤝 Claude Code = 秘書・部下・パートナー：自分がやりたいことを達成するためのエージェント。PC内のファイルを読み込んだり、コードを書いて実行したりするエージェント機能が強い。

🔍 ChatGPT = 高性能な検索エンジン：情報を引き出す使い方が多い。エージェント機能面ではまだ弱い。

Claude Codeを使うと選択肢の幅が広がり、できることが増える。投資対効果は100%戻ってくる（AIへの費用より、正しい使い方を教えてもらうことにお金を使う方が利口）。
Q7 AIで代替できないものは何だと思いますか？ 27:00〜
「責任」と「全体設計を理解する力」。
⚖️ 責任： AIはWhy・What・How・Whenを全部教えてくれる。でも最後のボタンを押すのは自分。失敗しても「AIが悪い」と言えても取り戻せない。責任は人間が取る。

🗺️ 全体設計の理解： カレーを作る例え——「カレーにアイスを隠し味で入れて」とAIが言った時、カレーを知っている人なら「それ要らないでしょ」と判断できる。知らない人は従ってしまう。

🚫 本末転倒の例：「トレーディングができない人がEAを作っても意味がない」。システムが代わりに稼いでくれるわけではなく、作った人の実力が反映されるだけ。
最終的に共通した結論は「AIを使っても、自分自身が成長し続けることは変わらない」。AIがどんどん賢くなっても、判断・評価・責任を取れる自分でないと、加速する車輪の中でただぐるぐる回るだけになる。

3キー洞察まとめ

このフリートークから得られた重要な考え方を抽出しました。

🧠 投資×AI の本質

準備の9割をAIが短縮する

投資の仕事は準備が9割。数ヶ月かかっていた分析検証が数時間になる。それがAIの最大の変化。

📱 現在地の把握

スマホ普及直前と同じ段階

「AIって役に立つの？」という疑問は、「タッチ決済って何？」と同じ質問。インフラ化するまでの移行期にいる。

⚽ スキーマの壁

テクニカル分析のAI化はあと5年

人間が言語化できていない感覚（スキーマ）を伝えられないと、AIも学習できない。テクニカルはまだその段階。

🔧 実用ツール

EAが2分で作れる時代

「SaaS is dead」——自分で作れるなら既製品を買う必要はない。資金管理自動化が特に実用的。

🤝 Claude Codeの位置づけ

秘書・部下・パートナー

ChatGPTが検索エンジンなら、Claude Codeはエージェント。「やりたいことを達成するための相棒」。

⚖️ 変わらないもの

責任と全体設計の理解

AIに全部任せてもカレーにアイスを入れてしまう。設計図を理解している人だけが、AIの誤りを判断できる。
